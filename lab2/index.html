Como usar o SQL Lab 2

  
Você vai montar, do zero, o banco da MangáVerso, uma loja de mangás e HQs. A trilha de missões fica no painel da direita e, na aba Diagrama, o DER e o MER do seu banco, que se desenham sozinhos a cada tabela que você cria.

  
Como funciona

  
1. Leia a missãoEla aparece no painel e numa faixa acima do editor

  
2. Escreva o SQLNo editor, usando a apostila como guia

  
3. ExecuteCtrl + Enter roda a instrução do cursor; Ctrl + Shift + Enter roda tudo

  
4. Veja o resultadoA missão é conferida sozinha. Se faltar algo, o painel diz o quê. O botão Conferir testa de novo

  
Se ficar preso

  
Dica / Ver respostaEm cada missão, para destravar sem desistir

  
Montar o banco até aquiApaga tudo e monta o banco com as respostas das missões anteriores à atual

  
RecomeçarApaga todos os bancos e volta ao começo da trilha

  
Diagramas

  
DERAs tabelas como ficam no banco: colunas, tipos, chaves primárias e estrangeiras

  
MERO desenho conceitual: entidades, relacionamentos e atributos

  
Botão de baixarSalva o diagrama como imagem (SVG)

  
Aba DiagramaFica ao lado de Consulta, no topo: troque entre as duas telas quando quiser

  
Boas práticas

  
Termine cada comando com ; e escreva textos entre aspas simples. Se aparecer um erro vermelho, leia a mensagem: ela diz o que o banco não entendeu. O seu progresso fica guardado neste navegador. Para levar o banco para outro lugar, use Salvar .sql e, depois, Abrir .sql.
