Como usar o SQL Lab Workbench

  
Um simulador do MySQL Workbench, rodando só no seu navegador. O banco loja_games já vem pronto, com o resultado das 40 etapas.

  
Atalhos

  
Ctrl + EnterExecuta a instrução onde o cursor está (ou o trecho selecionado)

  
Ctrl + Shift + EnterExecuta todas as instruções da aba

  
Ctrl + /Comenta ou descomenta as linhas selecionadas

  
Tab / EnterAceita a sugestão de autocompletar (Esc fecha)

  
Clique duplo na tabelaAbre SELECT * FROM tabela e executa

  
Para começar

  
SHOW TABLES;lista as tabelas do banco

  
DESCRIBE jogos;mostra as colunas de uma tabela

  
SELECT * FROM jogos;mostra todas as linhas

  
USE loja_games;escolhe o banco de trabalho

  
Boas práticas

  
Termine cada comando com ; e escreva textos entre aspas simples. Se aparecer um erro vermelho, leia a mensagem: ela diz o que o banco não entendeu. O botão Restaurar devolve o banco ao estado original.
